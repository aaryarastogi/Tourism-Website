It is an all-in-one website where users can book flights/hotels/train tickets and cabs . 

**Features**
1. User authentication and authorization.
2. Booking flights/hotels/trains tickets and cabs.
3. Get the confirmation of booking instantly via mail.
4. Payment Integration (Razorpay).
5. User can see its all the bookings as well and delete any if user wants to do it.
6. Rule-based chatbot through which also user can book tickets.
7. User can explore different destinations as well.
8. Created APIs also.

**Technologies:**
MERN stack, Tailwind CSS, Restful API's, Json Web tokens, Nodemailer package,, Framer Motion framework etc.
